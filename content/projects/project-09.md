  - heading: Goal
    text: >-
      Provide fill patterns for the charting tool that improve accessibility and
      work with the current design system. Existing patterns lacked logic, did
      not match system colors, and were hard to read at small sizes; the
      charting library did not offer guidance.


      TIMELINE


      2018–2019, Shipped


      Outcome


      - A pattern system built from basic elements, tuned for density in small
      spaces

      - Multiple prototypes using a CodePen tool the developer built

      - Recommendation to change the legend to a rectangle so patterns stay
      visible

      - Normal/reversed pattern modes; design-system colors interpolated (0.35 /
      0.6) to meet contrast standards


      Positive Outcomes Emerged  

      Patterns shipped, complied with usability/contrast standards, and were
      incorporated into the design system. "Project received well and improved
      accessibility across platform."


      My Role  

      Visual/product designer: research, exploration, prototyping and
      recommendations.


      My Team  

      A charting developer and the design systems team (leveraged existing
      standards; no user testing).The challenge
